# 토스측정 (토스증권 Open API 조회 전용 측정)

토스증권 Open API에서 어떤 데이터가 어디까지 오는지 재는 명령줄 프로그램입니다.
측정 결과로 "KIS 분봉 매일 수집을 끌 수 있는지"를 판단합니다.

- **조회 전용입니다.** 프로그램 안에 허용 목록(allowlist)이 있어, 시세·종목·순위·지수·섹터·계좌 조회 경로와
  토큰 발급(`POST /oauth2/token`) 외에는 요청을 보내기 전에 실패합니다. 주문·정정·취소·조건주문·주문 조회는 호출할 수 없습니다.
- `danta.sqlite`(단타분봉수집기 DB)는 읽기 전용으로만 엽니다.
- 결과는 `바탕화면/단타분석/toss_probe.sqlite`에, 실행 기록은 `바탕화면/단타분석/logs/toss_*.txt`에 남습니다.
- 로그와 화면에서 키·토큰·계좌번호, 사용자 폴더 경로(`<사용자폴더>`, `<바탕화면>`)를 가립니다.

## 준비

### 1. 키 발급과 허용 IP 등록 (토스증권 웹)

1. 토스증권 WTS(웹)에 로그인 → 설정 → Open API에서 `client_id`와 `client_secret`을 발급받습니다.
2. 같은 화면 아래 **허용 IP 관리**에 이 PC의 **공인 IP**를 등록합니다.
   등록하지 않은 IP에서 호출하면 403(`ip-not-allowed`)으로 막힙니다. 공인 IP는 브라우저에서 "내 IP"를 검색하면 확인할 수 있습니다.
   집 인터넷의 공인 IP는 공유기를 다시 켜면 바뀔 수 있습니다. 그때는 새 IP를 다시 등록해야 합니다.

### 2. 설치

1. GitHub Release에서 `토스측정_toss-v<버전>.zip`을 받아 원하는 폴더에 풉니다(다른 프로그램과 다른 폴더).
2. 처음 실행하면 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`을 묻습니다. 입력한 글자는 화면에 보이지 않고,
   설치 폴더 `secret/keys.env`에만 저장됩니다. 이 파일은 공유·업로드하지 마세요.
3. 설정을 바꾸려면 `config/toss_settings.env.example`을 `config/toss_settings.env`로 복사해 고칩니다.

### 토큰에 대해

- 토큰은 **클라이언트(client_id)당 1개만 유효**합니다. 새로 발급하면 이전 토큰은 즉시 무효가 됩니다.
- 이 프로그램은 토큰을 `바탕화면/단타분석/system/toss_token.json`에 저장하고 만료 10분 전까지 다시 씁니다.
- 같은 client_id를 다른 프로그램(나중의 자동매매기 등)과 동시에 쓰면 서로의 토큰을 무효로 만듭니다.
  그런 경우 토큰 파일을 함께 쓰도록 만들어야 합니다.
- 토큰이 무효·만료(`token-revoked`, `expired-token`, `invalid-token`)로 거절되면 1회만 다시 발급하고, 그래도 안 되면 중단합니다.

## 실행 순서

명령 프롬프트(cmd)나 PowerShell에서 설치 폴더로 이동해 아래 순서로 실행합니다.

| 순서 | 명령 | 하는 일 | 걸리는 시간(예상) |
|---|---|---|---|
| 1 | `토스측정.exe auth` | 토큰 발급, 계좌 목록(유형·개수만, 계좌번호는 가림) | 몇 초 |
| 2 | `토스측정.exe candles-depth --symbol 005930` | 1분봉·일봉을 과거로 넘기며 가장 오래된 날짜, 호출 수, 시간. adjusted(수정주가) true/false 비교 | 최대 수 분 |
| 3 | `토스측정.exe candles-check --date 20261124` | **KIS 없이** 토스 1분봉을 같은 날 토스 일봉과 대조 (정규장 누락, 시·고·저·종가, 거래량). 종목은 오늘 거래대금 순위 상위 5 + 100위 쪽 5 (`--symbols`로 지정 가능) | 1분 안팎 |
| (선택) | `토스측정.exe candles-compare --date 20261120 --n 10` | `danta.sqlite`(KIS 분봉)가 있는 PC에서만. 토스 1분봉과 KIS 분봉 비교 | 1분 안팎 |
| 4 | `토스측정.exe stock-info` | 종목 목록(KOSPI·KOSDAQ × 상장/상장폐지, 보통주 수), 상장폐지일 분포, 매수 유의사항, 투자자·프로그램 매매 과거 깊이 | 수 분 |
| 5 | `토스측정.exe market` | 장 운영 시간, KOSPI·KOSDAQ 지수 1분봉 깊이, 섹터 목록·순위 | 최대 수십 분 |
| 6 | `토스측정.exe rankings --watch 60 --times 30` | **장중에** 실행. 순위 조회 + 60초 간격 30회 실시간 순위 | 30분 |
| 7 | `토스측정.exe limits` | 지금까지 받은 그룹별 호출 한도 헤더 요약 | 즉시 |
| 8 | `토스측정.exe report` | 전체 요약(마크다운)과 판정. `바탕화면/단타분석/toss_report_<시각>.md`로도 저장 | 즉시 |

- 3번의 `--date`는 장이 끝난 거래일로 하세요. NXT(장후)까지 보려면 20시 이후에 실행합니다.
- `candles-compare`의 `--date`는 단타분봉수집기로 분봉을 받은 거래일이어야 하고, `DANTA_DB` 설정으로 파일 위치를 지정할 수 있습니다.
- 결과 로그(`logs/toss_*.txt`)와 보고서(`toss_report_*.md`)를 저장소 `docs/verify/toss/`에 올려 주세요.
  올리기 전에 키·계좌번호가 들어 있지 않은지 확인해 주세요.

## 측정 내용

### candles-compare: 시각 맞추기와 NXT

- 토스 종목 1분봉의 `timestamp`는 **봉 종료 시각**입니다(문서: `[timestamp - 1분, timestamp)` 구간 집계).
- KIS `minute_bar.time`과 맞출 때 두 규칙을 모두 계산합니다: shift 0(그대로), shift 1(1분 빼서 시작 시각으로).
  KRX 정규장(09:00~15:30) 종가 일치율이 높은 쪽을 정렬 규칙으로 보고합니다.
- 종목별로 봉 수, 시·고·저·종가 일치율, 거래량 합계 차이(%), 첫/마지막 봉 시각을 출력합니다.
- 토스 분봉에 NXT 거래가 섞였는지 보려고 봉 시작 시각 기준 08:00~09:00, 15:31~20:00 봉 개수도 출력합니다.
  KIS 분봉은 KRX(`J`)만입니다.

### 참고: 지수 캔들은 시각 기준이 다릅니다

- 지수(`market-indicators/{KOSPI|KOSDAQ}/candles`) 캔들의 `timestamp`는 **봉 시작 시각**입니다(문서 기준). 종목 캔들(종료 시각)과 다릅니다.

### candles-check: KIS 없이 자체 점검

- 그날 토스 1분봉을 봉 시작 시각으로 바꿔, 정규장에서 봉이 있어야 하는 381분(09:00~15:19 + 15:30 종가 단일가)이 다 있는지 셉니다.
  15:20~15:29(종가 단일가 접수)는 체결이 없을 수 있어 기대값에서 뺍니다.
- 같은 날 토스 일봉의 시가·고가·저가·종가가 정규장 분봉(거래량 있는 봉)에서 나온 값과 같은지, 전체 세션 분봉과 같은지 봅니다.
- 거래량 합계를 정규장 분봉 / 전체 분봉 / 일봉으로 나란히 보여 줍니다.
- 거래량 0인 봉 수를 세션별로 셉니다. 장전·장후에 거래량 0인 봉이 많으면 체결이 아니라 빈 시간을 채운 봉입니다.

### report: KIS 분봉 매일 수집 대체 판정

1. `candles-compare`(KIS 비교) 결과가 있으면: 토스 1분봉 30거래일 이상 + KIS 대비 정규장 종가 일치율 99% 이상
2. 없으면 `candles-check`(자체 점검) 기준: 토스 1분봉 30거래일 이상 + 정규장 분봉 완전성 99% 이상
   + 일봉 종가가 정규장 마지막 분봉 종가와 같은 종목 99% 이상 → "대체 가능 (자체 점검 기준)".
   이 경우 KIS 분봉과 값이 같은지는 확인하지 않습니다.

측정하지 않은 항목이 있으면 "판정 불가"로 표시합니다.

## 호출 한도

- 문서의 그룹별 초당 한도(예: 캔들 `MARKET_DATA_CHART` 20회, 종목 목록 `STOCK_ALL` 1회)의 **절반**으로 호출합니다(설정 `RATE_FACTOR`).
- 429(한도 초과)를 받으면 응답의 `Retry-After`초만큼 기다린 뒤 다시 시도합니다(최대 5회).
- 모든 응답의 `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`을 그룹별로 `ratelimit_log` 표에 기록하고,
  `limits` 명령으로 요약합니다.

## 저장 구조 (`toss_probe.sqlite`)

| 표 | 내용 |
|---|---|
| `results` | 명령별 측정 요약(JSON). `report`가 읽음 |
| `ratelimit_log` | 응답마다 그룹, 경로, 상태 코드, 한도 헤더 |
| `candle` | candles-compare에서 받은 토스 1분봉 |
| `ranking_snap` | 순위 조회 결과 (rankings, --watch) |
